从 Agent 打开你的乐谱

Ossia 本地服务已运行。请通过 Agent 或命令行打开谱面，获取可重复使用的文档直链。

  1. 接入 Agent
    在 Ossia 桌面应用的「Agent」面板中，点击你使用的 Agent 完成接入。
  2. 让 Agent 打开乐谱
    告诉它「用 Ossia 打开我的乐谱」，Agent 会使用 ossia_open 返回包含文档 ID 的谱面链接。
  3. 在浏览器中创作
    打开返回的链接，即可查看谱面、选择小节，并与 Agent 一起编辑乐谱。

使用命令行？运行 ossia open，再打开返回的链接。

链接可以收藏、刷新或在新标签页打开；同一文档的标签页共享选区。
Open scores through your connected Agent with ossia_open, or run ossia open in a terminal.
